# 4A I'm more cautious than I used to be (notatka źródłowa)

Źródło: Empower Upper-Intermediate, unit 4A, s. 44–46 (zrzuty ekranu z 2026-11-18) i własne zdania z pracy o prognozach dla AI, poprawione na lekcji.

## Zakres z podręcznika

| Część | Materiał |
|-------|----------|
| 1 Speaking | *spend money wisely*, *invest in*, *go from being poor to being very rich* |
| 2 Reading | słowa kluczowe z 2b (*low-income*, *catering college*, *discount vouchers*, *get into trouble with the head teacher*), *a life-changing decision*, *be headed for success*, *set sb on the path to*, *set up a company* |
| 3 Grammar | *used to* i *would* (stany vs nawyki), *no longer* vs *not … any more* i ich szyk (3c), przeformułowania z 3e |
| 4 Listening | *misery*, *myth*, *sensibly*, *go back to being poor*, *in the long term* |
| 5 Vocabulary | Cause and result: *lead to*, *cause / be caused by*, *have an effect on*, *affect*, *as a result of*, *result in*, *result from* (zdania z 5a i 5c) |
| 6–7 Listening, Speaking | *lifestyle*, *attitude to life*, *daily routine*, *leisure*, *study abroad*, *split up*; *How have you changed in the last ten years?* |

Poza zakresem lekcji (tag `extra`): *be / get used to doing* (kontrast z *used to do*) i idiom *from rags to riches*.

Pominięte, bo już są w kolekcji: *award* (`fce-vocabulary-sport-3a.tsv`), *sensible* (`fce-vocabulary-character-habits.tsv`), *be awarded sth* (`fce-collocations-athletes-3a.tsv`).

## Własne zdania (praca, prognozy)

| Notatka | Poprawiona wersja |
|---------|-------------------|
| We expect that the number of models getting through AI will increase dramatically (from few percent to more than 80%) | We expect the number of models built with AI to increase dramatically, from **a few** per cent to over 80%. |
| We expect that the number of people using raw python or SQL language will drop to zero. | We expect the number of people writing raw Python or SQL **to drop to** zero. |
| We foresee that ~~the~~ a dramatically increase of using AI will change the current job roles | We foresee that **the dramatic increase in** the use of AI will change current job roles, for instance from data scientist to AI manager. |
